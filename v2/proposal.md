
# Proposal: Мини-трекер учебных задач

## Цель

Создать автономный мини-трекер учебных задач на неделю, позволяющий управлять задачами, отмечать выполнение и отслеживать прогресс по запланированным часам.

Приложение должно работать в обычном браузере без установки библиотек, CDN, внешних ресурсов и API-ключей.

## Область изменений (Scope)

### Функциональность

- Отображение списка учебных задач.
- Добавление задачи с названием и оценкой в часах.
- Удаление задачи.
- Переключение статуса выполнения (`done`).
- Фильтрация: «Все», «Активные», «Готовые».
- Отображение суммарных часов и процента выполнения.
- Проверка корректности вводимых данных.
- Отображение ошибок рядом с соответствующими полями.

### Начальные данные

| Название | Часы | Выполнено |
|---|---:|---|
| Чтение | 2 | Да |
| Практика | 4 | Нет |
| Повторение | 2 | Нет |

Начальное состояние:
- Всего: 8 часов.
- Выполнено: 2 часа.
- Прогресс: 25%.

### Варианты поставки

**Вариант A — один файл**
- `tracker-v2.html`
- HTML, CSS и JavaScript находятся внутри файла.

**Вариант B — модульная структура**
- `index.html`
- `styles.css`
- `app.mjs`
- `domain.mjs`
- `tests/acceptance.test.mjs`

Оба варианта должны обеспечивать одинаковое пользовательское поведение.

## Ограничения

- Работа полностью на стороне клиента.
- Отсутствие внешних зависимостей.
- Читаемый интерфейс на ширине 390 px.
- Отсутствие горизонтальной прокрутки на указанной ширине.
- Подписанные поля ввода и кнопки.
- Корректные расчёты при пустом списке задач.

## Не входит в область изменений

- Серверная часть и внешние API.
- Подключение сторонних библиотек.
- Обязательная синхронизация с внешним хранилищем.
- Дополнительная функциональность вне перечисленных требований.

## Необязательное улучшение

Сохранение задач в `localStorage`.

Если хранилище недоступно, приложение должно:
- Показать понятное сообщение.
- Продолжить работу с данными в памяти.
- Не блокировать добавление, удаление и изменение задач.

## Критерий завершения

Решение соответствует функциональным требованиям, правилам валидации, расчётам и сценариям приёмки, указанным в спецификации.
